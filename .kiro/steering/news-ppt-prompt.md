# 新闻播报 PPT 生成提示词模板

## 基础模板

```
帮我生成一下当前{主题}的PPT，要求：

1. 主题风格：{明亮/暗黑}主题
2. 新闻数量：{3-5}条核心新闻
3. 时效要求：近{1-2}天的官方新闻
4. 来源要求：必须是官方权威媒体，出处需要标注在每页右栏底部
5. 图片要求：每条新闻左栏插入一张与内容相关的配图，需审核图片是否符合当页主题
6. 用 Pencil MCP 在当前画布上绘制
```

## 示例提示词

### 中东局势

```
帮我生成当前中东局势的PPT，明亮主题，写3-4条核心新闻，必须是官方新闻源，
出处标注在合理位置，每条新闻配一张相关图片并审核是否贴合主题，时效近两天，
用pencil画
```

### AI行业动态

```
帮我生成当前AI行业重大新闻的PPT，暗黑主题，写4-5条核心新闻，
必须来自官方科技媒体（TechCrunch/Reuters/Bloomberg等），
出处标注清楚，适当插入图片增加丰富性，时效近两天，用pencil画
```

### 国际财经

```
帮我生成本周国际财经要闻PPT，明亮主题，3-4条新闻，
来源限定为Reuters/Bloomberg/FT等权威财经媒体，
标注出处，配图需与财经主题匹配，用pencil画
```

## 关键要素清单

| 要素     | 说明             | 示例                                             |
| -------- | ---------------- | ------------------------------------------------ |
| 主题领域 | 你关注的新闻方向 | 中东局势、AI行业、国际财经、科技                 |
| 视觉风格 | 明亮或暗黑       | 明亮主题（白底蓝色调）/ 暗黑主题（深色底亮色调） |
| 新闻数量 | 3-5条为宜        | 写3-4条就够了                                    |
| 时效范围 | 近几天           | 时效近两天 / 近一周                              |
| 来源要求 | 官方权威媒体     | 必须是官方新闻，出处需要写上                     |
| 图片要求 | 是否需要配图     | 适当插入图片，需审核是否符合当页内容             |
| 输出工具 | Pencil MCP       | 用pencil画                                       |

## 进阶用法

- 加上"并导出为PNG"可以直接导出图片
- 加上"导出后用当前项目生成视频"可以串联视频制作流程
- 可以指定具体的新闻源，如"只用Reuters和AP的报道"
