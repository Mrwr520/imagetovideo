# 资讯视频生成工作流

当用户说"生成xxx视频"、"做一个xxx的视频"、"来个xxx话题的视频"时，执行以下完整工作流：

## 工作流步骤

### 1. 搜索热点素材
- 执行命令获取热搜：`python generate_auto_news.py --search "热搜" --search-only`
- 同时用 web_search 搜索用户指定话题的最新资讯，获取细节内容
- 如果用户指定了具体话题（如"科技"、"体育"），优先筛选相关内容

### 2. 编写脚本JSON
基于搜集到的素材，手动编写高质量脚本JSON，要求：

**标题规则：**
- 必须和内容强关联，包含具体热搜关键词
- 用悬念/反转/情绪写法，不能是平铺直叙
- 像抖音爆款标题那样吸引点击

**描述规则：**
- 设悬念引好奇，不是陈述总结
- 带emoji和hashtag
- 引导互动（评论区说说xxx）

**解说词规则：**
- 像朋友聊天，不像播报新闻
- 每条要有具体细节/数据/故事，不能只说"这个很火"
- 有自己的看法和评价
- 口语化，有语气词
- 不用"值得关注""引发热议"这种AI套话
- **整体时长控制在1分钟左右（约250-300字解说词总量）**，这是短视频节奏
- **重要：根据话题深度自行判断篇幅分配。**
  - 有故事/有画面的话题：重点展开，占30-40秒，讲细节讲场景
  - 纯资讯类：几句带过，占10秒左右
  - 所以一期视频建议只选2-3个话题，其中1个重点展开，剩下快速带过
- **图片数量自行判断**：根据内容节奏决定，总共4-6张合适（开场1张+内容2-4张+结尾1张），重点故事多配图，快速资讯少配图，不要固定每条话题一张

**图片提示词规则：**
- 固定主角：银发大眼动漫美少女"小星"，性感但能过审（露肩/锁骨/紧身但不暴露）
- 对话气泡必须是中文，且和当前话题内容直接相关
- 根据话题内容调整场景和表情
- 可以根据内容增加其他女性人物，每个人物都要：
  - 有自己的名字标签（如"小月"、"小夏"、"小悦"等）
  - 有独特的发色和造型（区分角色）
  - 同样性感但能过审（紧身/短裙/露肩，不能露点/不能内衣外穿）
  - 有自己的对话气泡（中文，和话题相关）
- 性感尺度参考：可以展示身材曲线、锁骨、肩膀、大长腿，但不能低俗（不能内衣、不能过度暴露）
- name tag显示角色名字

### 3. 保存脚本并生成视频
- 将脚本保存到 `output/` 目录
- 执行：`python generate_auto_news.py --script output/脚本文件.json --output-name 输出名`
- 图片生成每张约1-2分钟，总时长取决于段落数

### 4. 报告结果
- 告知用户视频输出路径、时长
- 展示标题和描述（可直接用于发布）

## 避免事项
- 不生成政治新闻内容
- 不用新闻播报风格（避免平台下架）
- 不用模板套话（"热度拉满""值得关注"）
- 图片不用写实风格，只用动漫风

## 脚本JSON格式
```json
{
  "title": "爆款标题",
  "description": "吸引人的描述 #hashtag",
  "opening": {
    "narration": "开场白",
    "image_prompt": "图片提示词"
  },
  "news": [
    {
      "headline": "简短标题",
      "narration": "有内容有细节的解说词",
      "image_prompt": "动漫美少女+中文气泡+场景"
    }
  ],
  "closing": {
    "narration": "结尾",
    "image_prompt": "图片提示词"
  }
}
```
