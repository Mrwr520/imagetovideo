# 动漫短剧自动化生产系统 - 需求文档

## 概述
基于现有图片转视频项目，扩展为动漫短剧自动化生产系统。用户选择领域和角色，系统自动搜索热点、生成剧本、出图、生成视频、配音合成，输出 15-20 秒竖版短视频。

## 核心需求

### 1. 领域选择 + 热点搜索
- 支持多领域：书籍名著、情感、军事、校园、职场、心理哲学、财经、科普、历史、民间神话等
- 领域配置化（config.toml），可无限扩展，不改代码
- 每个领域有子领域（如书籍名著→红楼梦/三国演义/道德经）
- 用户也可自由输入自定义话题
- 实时搜索该领域热门话题（复用现有 WebSearcher）
- LLM 提取 3-5 个适合做短剧的话题 + 热度评分

### 2. 角色管理系统
- 角色库：展示已有角色卡片（头像+名字+音色+风格标签）
- 新建角色：名字、外貌描述、3张参考图、绑定音色、默认情感
- 角色数据本地存储（characters/ 目录，每角色一个子目录）
- 选择参与本次视频的角色（1-3个），指定旁白/角色A/角色B
- **预留接口**：LoRA 模型文件字段（config.json 中 lora_path），当前版本不实现训练，但数据结构预留

### 3. 剧本生成（3 Agent 协作）
- Writer Agent：基于话题+角色+搜索素材生成结构化 JSON 剧本
- Validator：程序化硬规则校验（格式、字数、字段完整性）
- Reviewer Agent：LLM 审核内容质量（钩子、情感递进、点题、关联度）
- Prompter Agent：画面描述转精确出图提示词，统一风格
- 最多 3 轮迭代
- 输出严格对应 pipeline 的 TaskContext 格式

### 4. AI 出图（Phase 2）
- 接入 ComfyUI API 或通义万相 API
- 角色一致性：Phantom 多图参考（当前版本）/ LoRA（未来版本）
- 每张图可单独重新生成

### 5. 图生视频（Phase 3）
- Wan2GP + Wan 2.1 1.3B I2V（本地，8GB 显存）
- 或 Kling/Hailuo API（付费，质量更高）
- FFmpeg xfade 转场衔接场景

### 6. 多角色配音
- 火山引擎 TTS 多音色（已有）
- 根据剧本 character 字段自动切换音色
- 根据 emotion 字段设置情感参数
- word timing 精确字幕同步（已有）

### 7. 视频合成
- 视频片段 + 转场 + 配音 + 字幕 + BGM → 15-20秒 MP4
- 720x1280 竖版 9:16

## 输出规格
- 时长：15-20 秒
- 分辨率：720x1280（9:16）
- 场景数：3-5 个
- 格式：MP4 H.264
